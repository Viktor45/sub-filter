# 常见问题

## 为什么需要这个程序？

代理订阅有时会因为一条无效的行而损坏，导致客户端（路由器或应用中的）
拒绝整个订阅。这个工具会自动移除损坏、不安全或不需要的服务器，而不必
手动清理订阅。它对路由器和资源受限的设备尤其有用。

> ⚠️ 程序**不检测代理的可用性**——只检查配置的正确性。

## 程序具体会拒绝什么？

使用自带的 `config/rules.yaml` 时：

- `security=none`（或缺少 `security`，按 `none` 处理）的 VLESS，或缺少
  `sni` 的 VLESS
- `security=reality` 时缺少 `pbk`、`type=grpc` 时缺少 `serviceName`、
  或 `ws`/`httpupgrade`/`xhttp`/`splithttp` 缺少 `path` 的 VLESS
- `security` 为 `none`、`zero` 或 `null`（未加密）的 VMess
- 带有任何 `flow` 参数的 Trojan（已在 Xray-core 2024+ 中移除）
- 使用已废弃 CFB/CTR 加密的 Shadowsocks
- 缺少 `obfs`/`obfs-password` 或带 `insecure=1`/`true` 的 Hysteria2
- 名称命中 `delete`「违禁词」规则的服务器
- 与所请求国家列表不匹配的服务器（启用国家过滤时）
- 方案不受支持或格式错误的链接

完整规则集及调整方法见 [FILTER_RULES](FILTER_RULES.md)。

## 为什么要按国家过滤？

为了只使用您想要辖区内的服务器——例如提升速度和连接稳定性。

## 国家过滤如何工作？

程序会扫描每条代理链接的**片段**（`#...`），查找所请求国家的以下任意
字符串：

- ISO 3166-1 alpha-3 代码：`AND`
- 国旗表情：`🇦🇩`
- 通用名称：`Andorra`
- 本地名称：`Principat d'Andorra`

匹配**不区分大小写**，并支持 **URL 解码**。您传入的两字母代码
（`c=AD`）用于选择国家，但不会在片段中直接搜索。没有片段的链接无法通过
国家过滤。

## 在哪里查看被拒绝的内容？

在服务器模式下，缓存目录（默认 `/tmp/sub-filter-cache`）为每个源与国家
组合保存：

- `orig_<id>[_c_<代码>].txt` — 原始下载的订阅
- `mod_<id>[_c_<代码>].txt` — 过滤后的结果
- `rejected_<id>[_c_<代码>].txt` — 被拒绝的行，每行前面都有一行
  `# REASON: ...`

`<代码>` 是排序后用下划线连接的国家代码，例如 `?id=1&c=AD` 对应
`rejected_1_c_AD.txt`。

## 为什么会收到「400 Invalid User-Agent」？

`/filter` 和 `/merge` 只接受 `User-Agent` 以内置前缀（`clash`、`happ`、
`incy`）开头，或匹配 `config/uagent.txt` 中某个模式的请求。内置前缀
区分大小写，因此使用 `curl` 时请用 `User-Agent: clash`（小写）。大多数
流行客户端已被 `uagent.txt` 覆盖。

## 我的数据会被发送到任何地方吗？

不会。所有处理都在**本地**进行。程序只做三件事：

1. 下载您配置的公共订阅，
2. 在您的设备上处理它们，
3. 将结果交付给您的客户端（Clash、路由器等）。

**不会向任何第三方发送数据。** 该工具可以作为后台服务器运行，也可以以
一次性 CLI 模式运行，不需要云服务，并且可以在您自己设备上的 Docker
容器中运行。
